# Beside Pet

반려동물을 떠나보낸 보호자를 위한 AI 감정 지원 웹서비스. 대화 웹(`apps/web`), 소개 사이트(`apps/landing`), API(`apps/api`), 인프라(`infra/`)를 한 레포에서 관리한다.

- 레포: `JadenKimDev/beside-pet`
- 개발 하네스: Claude Code 팀(팀장과 팀원 에이전트), PRD 와 GitHub 이슈, 작업 원장. 에이전트용 안내는 [`CLAUDE.md`](./CLAUDE.md).

시작:

```bash
pnpm install
pnpm test
```
