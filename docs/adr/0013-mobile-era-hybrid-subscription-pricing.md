# 모바일 시기의 요금제는 구독과 1회권의 하이브리드였다. 웹에는 결제가 없다

> `deprecated`: 웹 제품은 결제를 의도적으로 뺐고, 이 요금제를 대신하는 결정은 아직 없다. 다시 과금을 정할 때 출발점과 함정으로 쓰려고 남긴다.

## 맥락

사업계획서 v2.2(2026-02-28)는 오프라인 그리프 지원(회당 100에서 150달러)보다 훨씬 싼 월 구독을 가치 제안으로 두었다. 결제는 RevenueCat 으로 붙일 계획이었고, 중단 때 구독 화면과 프로모션 코드까지 만들었지만 실제 결제는 붙지 않았다.

## 결정

당시 정한 것:

| 상품 | Basic | Premium |
|---|---|---|
| 1회권 | $1.99 | $2.99 |
| 주간 | $3.99 | $5.99 |
| 월간 | $7.99 | $12.99 |
| 연간 | $59.99 | $99.99 |

- 대화의 질은 두 플랜이 같다. 차이는 세션 뒤의 콘텐츠(AI 위로 편지, 감정 리포트, 기념일 알림)와 세션 수, 사진 수, 내보내기다. Basic 에서 잠긴 기능을 보여 Premium 으로 이끈다.
- 과금 단위는 턴 묶음이 아니라 세션이다. 활성 세션은 하나, 2시간 비활성이면 자동 종료, 7턴 이하로 자동 종료된 세션은 소진하지 않는다(세션 보호).
- 위기 감지와 전문 자원 연결은 무료를 포함한 모든 플랜에 있다.
- 첫 구매 할인만 하고 무료 코드는 쓰지 않는다.

## 버린 것

당시 오갔던 안: 세션팩 IAP 전용(로드맵 v2), Basic $6.99(옛 문서들), 연간 $69.99와 $129.99(컨설팅 리포트), 무료 체험 3회와 1회.

## 결과

- 웹 제품은 결제를 의도적으로 뺐다. 가입은 승인제(ADR-0007)이고 사용량 제한도 없다.
- 이 요금제를 다시 쓰지 않는 이유: 모바일 기능(편지, 사진, 기념일 알림)을 전제로 차등을 두었고, 비용 계산이 당시 모델 단가(GPT-5 mini 세션당 약 $0.015에서 $0.046)에 기대었다. 모델이 바뀌면(ADR-0010) 계산이 달라진다.
- 다시 과금을 정할 때 지킬 것: 위기 자원은 결제 뒤에 두지 않는다(ADR-0004). 가격 비교 문구는 "치료보다 싸다"가 아니다(ADR-0003).
- 옛 문서들은 같은 상품을 다른 값으로 적었다. 무료 체험 횟수(3회와 1회), 턴 상한(30턴, 20턴, 90턴, 토큰 기준), Basic 가격($6.99와 $7.99)이 문서마다 달랐고 당시 정본은 시드 데이터($7.99)였다.
