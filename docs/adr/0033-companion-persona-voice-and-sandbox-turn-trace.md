# 동반자의 결은 한 사람의 페르소나이되 이름·개인사·자기 반려동물은 두지 않고, 턴 추적은 sandbox 전용이다

## 맥락

#18 과 #27 뒤에도 답은 상투적이었다. 2026-10-22 의 후속 조사(`docs/research/2026-10-22-comfort-voice-followup.md`, 로컬)는 남은 상투성이 문자열이 아니라 **동작의 반복**임을 보였다. 비위기 턴 21개 중 20개가 감정 추정, 뜻 부여, 허락 중 하나를 담고, 거의 모든 답이 "되받기 → 그중 하나 → 질문" 틀이었다. 10대, 70대, 영어 화자에게 어미만 다르고 결이 같았다. 같은 조사의 소규모 실측(발화 5개 × 3회, Sonnet 맹검)에서 효과가 가장 큰 수단은 **결이 뚜렷한 한 사람의 페르소나**였다(선호 13/15, 뜻 부여 40%→20%). 조사의 초안은 그 사람에게 이름, 나이대, 자기 반려동물을 보낸 경험을 주었다.

한편 "왜 이 답이 나왔나"를 되짚을 자리가 없었다. 프롬프트 본문, `TurnStyle` 의 결정, 위기 판정의 원문 모두 저장하지 않는다(ADR-0027 은 `TurnStyle` 을 저장하지 않기로 했다).

## 결정

1. **동반자는 한 사람의 결을 갖되, 사람을 지어내지 않는다.** 발화 지시문(`support/prompt/reply.rs`, 0.4.0)의 정체 문장은 결만 둔다: 말수가 적고 담백하다, 가끔 마른 유머, 침묵을 믿고 채우지 않는다, 사람의 감정을 설명하거나 그 뜻을 말해 주지 않는다, 알아차린 것을 말한다. 이름, 직업, 나이, 자기 반려동물과 그 이름, "자기 경험 한 줄"은 두지 않는다. 상담·치료가 아니라는 부정형 한 문장은 유지한다(ADR-0003 의 면책 자리). 테스트가 이 낱말 목록을 든다.
2. **대명사 줄을 둔다.** 사용자의 저/제/나/내(영어는 I/me/my)는 사용자이고, 되받을 때는 호칭을 쓰거나 대명사를 뺀다. 조사 초안의 "보호자님"은 쓰지 않는다. 반말 세션(10대 인물)에 맞지 않기 때문이다.
3. **문체 지시는 긍정형 한 줄만.** 금지 목록, BAD 예시, GOOD 예시를 넣지 않는다(ADR-0027). 예시는 그 어미를 그대로 옮겨 10대 반말 대화를 존댓말로 되돌렸다(실측 3/3).
4. **화법 규칙에 둘을 더한다.** 사용자의 짧은 말(15자 이하) 뒤에는 한두 문장·질문 없음, 직전 답에 감정 추정·뜻 부여·허락이 있었으면 이번엔 관찰이나 직접 답. 패턴은 `turn_style` 한 곳에 한국어·영어로 두고, 사용자가 직전에 쓴 낱말은 세지 않는다.
5. **턴 추적은 sandbox 전용이다.** `turn_analyses.trace jsonb NULL` 에 그 턴의 프롬프트 버전, 블록 이름과 길이, 화법 결정(`TurnStyle::decisions()`), 조립된 시스템 프롬프트 전문을 둔다. `APP_ENV=sandbox`(ADR-0021) 일 때만 채우고 production 은 늘 NULL 이다. 새 환경 변수는 없다. 분석 응답에 `trace` 가 `Option` 으로 더해지지만 production 에서는 NULL 이라 JSON 에서 칸이 빠진다. 이것은 ADR-0015(겉을 바꾸지 않는다)의 예외이되 production 응답은 바뀌지 않는다. ADR-0027 의 "TurnStyle 은 저장하지 않는다"는 그대로다. 추적은 저장이 아니라 sandbox 의 관찰 기록이고, sandbox 의 세션은 QA 계정과 지어낸 인물뿐이라 프롬프트 전문을 둔다.

## 버린 것

| 대안 | 버린 이유 |
|---|---|
| 이름·나이대·자기 반려동물 경험을 가진 페르소나(조사 초안) | 거짓 경험담이 된다. 떠나보낸 사람에게 지어낸 상실을 말하는 것은 제품이 설 자리가 아니다. 효과도 세션 단위 실측이 없다(턴 단위 소규모뿐) |
| 어투별 GOOD 예시 묶음 | 실측에서 예시의 어미가 그대로 옮아 반말 세션을 깼다. 효과도 작다(10/15) |
| 호칭을 "보호자님"으로 고정 | 반말 세션에 맞지 않는다. 대화의 어투에 맞는 호칭을 쓰거나 대명사를 빼게 한다 |
| production 에서도 추적을 저장 | 시스템 프롬프트 전문에 사용자의 말과 반려동물 정보가 들어간다. 실제 사용자의 대화를 한 번 더 복제하는 것이고, 필요한 곳은 실측(sandbox)뿐이다 |
| 추적을 별도 테이블로 | 턴 하나에 하나뿐인 관찰이고 `turn_analyses` 가 이미 턴 단위의 사실 행이다. NULL 칸 하나가 더 단순하다 |
| 위기 판정 모델의 원문(YES/NO)도 추적에 넣기 | `safety` 를 건드리지 않는다. 필요가 보이면 따로 |

## 결과

- 프롬프트 버전 0.4.0(minor, 같은 기준선에서 비교. ADR-0022). 실측 기준은 `outputs/chat-eval/2026-10-22/`(#27 마감)다.
- chat-eval 의 자동 검사에 동작 비율(감정 추정, 뜻 부여, 허락), 대명사 뒤집힘, 첫 인사 피복, 길이 분산이 더해지고, 인물 md 의 턴 표 옆에 추적이 보인다.
- production 의 응답과 DB 행은 바뀌지 않는다. `trace` 가 production 에서도 채워지게 되면 `infra/docker/scripts/sandbox-scrub.sql` 의 목록에 더해야 한다.
- 동작 패턴의 재현율과 정밀도는 D 등급이다(단일 조사의 사전). 실측에서 어긋나면 패턴부터 고친다.
