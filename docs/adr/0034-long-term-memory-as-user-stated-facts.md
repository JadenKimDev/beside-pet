# 장기기억은 사용자가 말한 사실의 행이다. 요약·전사 주입·벡터는 쓰지 않고, 현재 사실은 뷰가 내며 매 턴의 프롬프트에 넣는다

## 맥락

세션을 넘어 이어지는 기억이 없었다. 재개 때 가장 최근 세션의 전사 꼬리 6개와 요약 한 줄이 첫 인사 프롬프트에만 들어갔고 그 뒤 턴에는 직전 세션이 없었다. 2026-10-22 의 3달치 궤적 실측(`outputs/chat-eval/2026-10-22-baseline/`, 로컬)에서 석 달 뒤 돌아온 사용자에게 지난 세션의 구체를 되받는 턴이 0/5 였고, 재개 인사가 경과 시간을 모르고 직전 세션의 마지막 화제(죄책감)를 바로 꺼냈으며, 도달 과제를 이어받아 복귀 세션이 3턴 만에 닫혔고, 위기로 닫힌 뒤 첫 세션이 그 일을 모르고 시작했다.

조사(`docs/research/2026-10-22-long-term-memory.md`, 로컬)의 결론: 이 제품의 한 사람 분량은 모델의 창에 들어가고, 이 규모의 벤치마크에서는 전부 넣기 ≥ 추출 기억 ≥ RAG 였다. 전사 전체를 넣는 파일럿은 "여기서만 하는 얘기"를 다시 꺼내고 정정 전 진술을 되살렸다.

## 결정

1. **저장하는 것은 사용자가 말한 사실 한 문장씩의 행이다.** `pets`(아이의 이름과 상태)와 `memory_notes`(종류, 아이, 문장, 말한 시각, 출처 세션과 발화 순번). 동반자의 말, 요약, 해석은 저장하지 않는다. 행은 "추출이 일어났다"는 사실이고, 정정은 옛 행을 고치지 않고 새 행이 옛 행을 `superseded_by` 로 무효화한다. 현재 사실 목록은 뷰 `current_memory` 가 낸다("데이터를 두는 원칙"). 정정 이력은 사용자에게 보이지 않는다.
2. **종류는 일곱이다.** 반려동물, 사람, 물건, 장소, 날짜, 습관·의식, 선호. **건강과 직업은 종류에 없다.** 사용자가 말해도 저장하지 않는다(2026-10-22 사용자 결정).
3. **추출은 답이 끝난 뒤 비동기로 모델이 JSON 으로 하고 코드 게이트가 거른다.** 턴 지연에 더하지 않고 실패해도 대화는 그대로 간다. 게이트는 종류 밖, 이번 발화가 아닌 순번, 발화 본문에 없는 숫자와 날짜(모델이 추론한 날짜)를 버린다. 온보딩 프로필에 없는 아이는 사용자가 이름과 함께 말했을 때만 사실로 들어오고, 같은 이름이 두 번 나오면 `pets` 행이 된다. 모델 호출은 `llm_calls` 에 `memory_extract` 로 사실만 남는다(ADR-0022).
4. **매 턴의 시스템 프롬프트에 "이 사람에 대해" 블록으로 들어간다.** 재개 인사만이 아니다. 지금 세션의 아이를 먼저, 다른 아이는 이름과 상태만. 50줄을 넘으면 최근 말한 순으로 자른다(검색이 아니다). 블록은 **죽음의 정황과 자책을 저장해도 동반자가 먼저 꺼내지 않는다**고 지시한다. 사실을 그대로 인용하지 않는다.
5. **옵트아웃은 발화 하나다.** "그건 기억하지 마"가 들어간 발화의 사실은 저장하지 않고 `memory_optouts` 에 내용 없는 사건만 남는다.
6. **보존은 마지막 활동 뒤 12개월이다.** 서버 기동 때 그보다 오래된 계정의 기억 행을 지운다. 기간은 코드 상수다. 대화를 지우면 그 세션이 출처인 기억 행도 같은 트랜잭션에서 지운다(ADR-0006 의 연쇄를 잇는다).
7. **재개의 규칙(ADR-0005 의 6 을 잇는다).** 직전 세션은 "마지막 메시지 시각이 가장 최근인 세션"이다(생성 시각이 아니다). 지난 세션이 클로징이었거나, 위기로 닫혔거나, 경과가 7일을 넘으면 과제 1 부터 다시 시작한다. 그 밖은 도달 과제. 재개 인사는 경과가 7일을 넘을 때만 경과를 한 줄로 받되 공백을 평가하지 않고, 위기로 닫혔으면 그 일을 한 줄로 받고 지금 어떤지 한 번 묻되 위기 내용은 반복하지 않는다. 경과 일수는 서버가 셈해 넣는다. 지원 수준은 바꾸지 않는다.
8. **기억 본문은 상담 내용과 같은 규칙이다.** 로그와 오류 문구에 싣지 않고, 에이전트는 `memory_notes.text` 를 읽지 않으며, sandbox 복사본에서는 `pets.name` 과 함께 자리 표시자로 바뀐다.

## 버린 것

| 안 | 이유 |
|---|---|
| 벡터 저장소와 메모리 프레임워크(mem0, LangMem 류) | 한 사람 분량이 창에 들어가는 규모라 검색이 필요 없고, 벤치마크에서도 이 규모는 전부 넣기가 앞선다. 의존성과 운영 자원이 늘기만 한다 |
| 지난 세션 전사 전체 주입 | 파일럿에서 "여기서만 하는 얘기"를 다시 꺼내고 정정 전 진술을 되살렸다. 전사 꼬리의 확대는 사실 목록만으로 구체 되받기가 모자랄 때 다음 PRD 로 |
| 모델이 쓴 요약을 저장 | 요약은 해석이고 틀리면 고칠 자리가 없다. 사실 행은 정정으로 무효화할 수 있다 |
| 종류에 건강·직업 | 사용자 결정. 민감 정보를 저장할 이유가 대화의 질에 비해 크지 않다 |
| 위기 뒤 재개를 고정 안부 문구와 지원 수준 2 로 시작 | 고정 문구는 결(ADR-0033)을 깨고, 지원 수준을 바꾸면 위기 재판정의 뜻이 흔들린다. 지시 줄로 둔다 |
| 기억을 보고 지우는 화면 | 엔드포인트의 겉이 늘어나므로 웹과 함께 다음 PRD(ADR-0015) |

## 결과

- 사용자가 "그 담요"라고만 해도 어떤 담요인지 받고, 말을 바꾸면 새 사실이 옛 사실을 대신한다.
- 재개 인사가 경과와 위기를 알고, 석 달 뒤 복귀가 과제 1 부터 다시 간다.
- 추출 호출이 턴마다 하나 더 든다. 비용은 `llm_calls` 의 뷰로 센다.
- 처리방침 문구와 사용자가 기억을 보는 화면은 다음 PRD 다. 그때까지 사용자는 기억을 보지 못하고 지우려면 대화를 지운다.
