# 상담 모델 A/B 에서 GPT-5 mini 가 비용으로 이겼지만, 그 결론은 2주를 못 갔다

## 맥락

모바일 시기에 상담 모델을 Gemini 2.5 Flash 에서 바꾸려고 후보를 비교했다. 무료 체험과 구독의 턴 상한(30턴)을 모델 비용으로 정하고 있었으므로, 세션당 비용이 요금제와 바로 이어졌다(ADR-0013).

## 해 본 것

1. 먼저 걸렀다. Gemini 2.5 Flash 는 프롬프트 준수가 모자라고 반복하며 Haiku 보다 느렸다. Gemini 2.5 Pro 는 첫 토큰이 3초를 넘었다. Claude Haiku 3.5 는 2026-02-19 에 은퇴했다. GPT-4.1-mini 는 무난했지만 GPT-5 mini 보다 나은 점이 없었다.
2. 남은 셋을 8개 시나리오로 비교했다(GPT 계열은 GPT 전용 프롬프트).

| 항목 | Claude Haiku 4.5 | GPT-5 mini | GPT-4.1-mini |
|---|---|---|---|
| 첫 토큰 평균 | 609ms | 851ms | 570ms |
| JSON 준수 | 8/8 | 8/8 | 8/8 |
| 내부 라벨 노출 | 1/8 | 0/8 | 0/8 |
| 피로 신호 대응 | 1건 실패 | 통과 | 2건 실패 |
| 30턴 비용 | $0.050 | $0.015 | $0.015 |
| 90턴 비용 | $0.149 | $0.046 | $0.045 |

3. GPT-5 mini 로 10턴 멀티턴을 돌렸다. JSON 10/10, 라벨 노출 0, 금지 표현 0, 첫 토큰 평균 1,280ms(대화가 길수록 늘었다), 10턴 비용 $0.0051.

## 결과

- 결정: 일반 세션은 GPT-5 mini(`reasoning_effort: minimal`), 턴 상한은 90턴으로 늘림("GPT-5 mini 90턴이 Haiku 30턴보다 싸다"). Haiku 는 환경 변수 하나로 돌아갈 수 있는 대체로 남겼다. 첫 세션은 전환을 위해 Sonnet 급을 쓰자는 안도 같이 적었다.
- 같은 문서의 "핵심 결론" 절은 여전히 "일반 세션 Haiku" 라고 적고 있어, 문서 안에서도 결정이 엇갈렸다.
- 2주 뒤의 실측에서 GPT-5 mini 는 턴 평균 8에서 9초, 첫 인사 18초 안팎으로 느렸고 self-check 와 규칙을 지키지 않았다. 3월 15일과 16일 문서는 Haiku 를 1순위로 되돌렸다(DEV-2026-03-15-user-simulator-flips-ranking).
- 교훈: 짧은 시나리오 8개와 첫 토큰 시간으로는 긴 대화의 지연, 반복, 규칙 준수를 볼 수 없다. 모델을 고를 때는 20턴 이상의 대화와 턴별 전체 응답 시간을 같이 잰다. 세션당 비용이 1센트 단위일 때는 비용보다 품질과 지연이 먼저다.
