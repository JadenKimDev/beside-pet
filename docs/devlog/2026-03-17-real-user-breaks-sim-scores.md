# 실제 사람과 대화하자 시뮬레이터에서 5점이던 품질이 3점으로 떨어졌다. "몰라"가 이어질 때 방향을 바꾸지 못했다

## 맥락

모바일 시기 3월 15일과 16일의 시뮬레이터 점수는 Haiku 5.0, Flash 4.7 에서 5.0 이었다. 3월 17일 실제 사람이 앱에서 대화해 보았다. 대화 기록 원문은 이 레포에 옮기지 않고 교훈만 적는다.

## 해 본 것

1. Haiku 로 실제 대화 35턴(14분)을 하고 시뮬레이터 기반 Flash 20턴과 같은 기준으로 채점했다.
2. 리팩터링 전의 실제 대화 두 건(Flash, 40메시지와 31메시지)을 다시 읽었다.
3. GPT-5 mini 로 "질문하는 이유를 설명하라"(question_framing) 규칙을 넣고 37메시지 시뮬레이션을 했다.

## 결과

- Haiku 실제 대화 3.0점, Flash 시뮬레이션 4.7점. Haiku 는 19번째 턴부터 35번째 턴까지 "가장 X한 것은?" 꼴의 감정 명명 질문을 되풀이했다(반복 회피 1점). 사용자가 "몰라", "잘 모르겠어"를 세 번 이어 보냈는데 매번 같은 유형의 질문으로 받았다. 보고서 스스로 "Flash 점수는 시뮬레이터 기반이라 과대평가일 가능성이 높다"고 적었다.
- 리팩터링 전 Flash 실제 대화: 40메시지, 24분, 입력 147K 토큰 대 출력 2.2K 토큰, 10점 만점에 5.5점. 사용자가 "예를 들어서 설명해 줘"라고 직접 요청해야 했다. 다른 세션은 반복 질문이 5번 넘었고, 반려동물을 "친구"라고 불러 사용자가 혼란스러워했다.
- question_framing 은 과하게 적용됐다. "왜 묻냐면" 류가 14번 나왔고 사용자 역할은 "무슨 말인지 모르겠다"고 했다. 한국어 사용자인데 첫 인사가 영어로 나왔다. "첫 인사 하드코딩" 판의 기록은 같은 내용의 복사본이라 그 시도의 결과는 남아 있지 않다.
- 교훈: 비몰입("몰라")은 실패 신호가 아니라 방향을 바꾸라는 신호다. 웹 API 의 깊이 게이트는 비몰입이 두 번 이어지면 같은 단계에 붙잡지 않고 부드럽게 넘어간다(ADR-0005, `DISENGAGE_EXIT = 2`). 이 실측에서 드러난 문제를 겨냥한 규칙이다.
- 시뮬레이터 점수는 실제 사용자 테스트를 대신하지 못한다. 모델이나 흐름을 바꾼 뒤에는 짧은 실제 대화를 한 번은 한다. 이때 쓰는 계정과 대화는 지어낸 것이어야 하고, 실제 사용자 데이터를 개발 DB 로 옮기지 않는다.
